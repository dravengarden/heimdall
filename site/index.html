The shortest useful path

Validate. Run. Inspect.

Heimdall is intentionally narrow. The normal workflow is a small loop that keeps policy decisions visible.

01Validate

Reject schema and capability mistakes before the workload starts.

heimdall config validate
02Run

Attach one transient cgroup and forward the child exit status.

heimdall run -- your-command
03Inspect

Use read-only evidence when an agent or operator needs the reason.

heimdall agent
Scope is the contract. Only the attached command cgroup is redirected. Its foreground session follows policy and never silently falls back to direct egress. See the command surface →
