# heimdall-config

Strict TOML, YAML, and JSON configuration schema for
[Heimdall](https://github.com/dravengarden/heimdall). Install the public command
with:

```bash
cargo install heimdall-egress --locked
```

This crate is published separately only because Cargo requires registry
dependencies to be independently available. The CLI schemas and documentation
remain the product contract; this pre-1.0 Rust API may change.
