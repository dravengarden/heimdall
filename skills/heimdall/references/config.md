# Editing `heimdall.{ncl,yaml,json,toml}`

The single config file declares everything heimdall does:

```
runtime     — eBPF + listener + retention + tap + defaultEgressPolicy
connections — named SOCKS5 / direct upstreams
routing     — unit/slice selector → connection (rule → default)
cli         — defaults for `heimdall <subcommand>` invocations
```

## Authoritative schema reference

**Always read `/etc/heimdall/README.md` before editing.** It's
auto-generated by `heimdall init` and version-locked to the daemon
binary. It documents every field, every operator, every default,
plus validation rules and common errors.

This file is an entry-point pointer, not the spec.

## Recommended format: Nickel

`heimdall.ncl` is recommended because it imports `lib.ncl` and
validates the whole record at evaluation time. Typos (`unit`
instead of `units`) and wrong types fail at `nickel export`, before
the daemon ever loads the file.

YAML / JSON / TOML are accepted (extension-detected), validated by
`serde(deny_unknown_fields)` at daemon load time.

## Workflow

```bash
# 1. Read the schema reference
less /etc/heimdall/README.md

# 2. Edit
sudoedit /etc/heimdall/heimdall.ncl

# 3. Validate before applying
heimdall config validate                 # exit 0/1, human-readable
heimdall config validate --json          # AI-friendly

# (optional) Nickel-side validation
nix-shell -p nickel --run "cd /etc/heimdall && nickel export -f json heimdall.ncl > /dev/null"

# 4. Apply
sudo systemctl restart heimdall
heimdall status                          # connections=N rules=M
heimdall flows search --since 1m --json  # smoke-test routing
```

## Inspecting the live config

```bash
heimdall config path        # which file is auto-discovered
heimdall config show        # raw file content
heimdall config show --json # JSON envelope: {path, format, content}
heimdall config validate    # parse + schema check, exit 0/1
```

All read-only — safe in CI / pre-commit hooks.

## Common edits

### Add a new SOCKS5 upstream

```nickel
connections = {
  default  = { ... },
  myproxy  = {
    description = "...",
    type        = "socks5",
    addr        = "10.0.0.5:1080",
    auth = {                          # optional
      username     = "alice",
      passwordFile = "/etc/heimdall/secrets/myproxy.pw",
    },
  },
  ...
}
```

Then drop the password file:

```bash
printf '%s' 'PASSWORD' | sudo tee /etc/heimdall/secrets/myproxy.pw > /dev/null
sudo chmod 0400 /etc/heimdall/secrets/myproxy.pw
sudo chown root:root /etc/heimdall/secrets/myproxy.pw
```

### Route a unit / slice to that upstream

Append to `routing.rules` (first match wins, top-down):

```nickel
{
  name    = "my-rule",
  "match" = {
    slices = [ "app.slice" ],
    units  = [ "prefix:tenant-a-" ],
  },
  use     = "myproxy",
  observe = true,                     # capture plaintext via tap
}
```

`units` and `slices` are lists of `MatchValue`: bare exact strings,
or one of `regexp:` / `prefix:` / `suffix:` / `keyword:`. For
boolean composition (`all` / `any` / `not`), see
`/etc/heimdall/README.md`.

### Per-process override (no config edit)

For ad-hoc CLI work use `heimdall run` — it registers a transient
cgroup with its own decision via `POST /api/cli/register`. See
`run.md`.

### Change `heimdall run` defaults

```nickel
cli = {
  run = {
    "default" = {                     # baseline (no --profile flag)
      connection = "default",
      observe    = true,
      dns        = "fake",
    },
    profiles = {
      corp   = { connection = "corp" },
      silent = { observe = false },
    },
  },
}
```

Resolution: `flag > [profile.NAME] > cli.run.default > compiled-in fallback`.

### Flip default egress policy (emergency fail-open)

```nickel
runtime = {
  ...
  defaultEgressPolicy = "bypass",     # default: "redirect"
}
```

`redirect` is current production behaviour: unclassified cgroups
under `runtime.cgroup` go through the relay, falling back to
`connections.default`. `bypass` makes them skip the relay entirely
— emergency override when the relay or upstream is misbehaving and
you need traffic to flow direct without stopping the daemon (which
would also drop tap visibility). Restart heimdall after the change.

## Reserved values

- Connection name `system` is **reserved**. Don't declare
  `connections.system`. Use `use: "system"` in a rule to mean
  "skip the eBPF redirect, no relay involvement."
- Connection name `default` is **required**. Validation fails
  without it.

## Validation gates

The daemon refuses to start when:

- `apiVersion` ≠ `"heimdall.io/v1alpha1"`
- `kind` ≠ `"HeimdallConfig"`
- `connections` doesn't include `default`
- Any rule's `use` references an unknown connection (and isn't `"system"`)
- A `passwordFile` is unreadable

All surface in `journalctl -u heimdall` immediately on restart.
